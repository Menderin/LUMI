# LUMI

Proyecto de desarrollo de un robot seguidor de personas.

El desarrollo técnico se guía por el alcance, los incrementos, las historias de usuario y los criterios de aceptación definidos en la gestión del proyecto.


## Organización del repositorio

Consulta [la guía de estructura](Agents/estructura-repo.md) para conocer la finalidad y el contenido de cada carpeta. Las instrucciones para agentes comienzan en [AGENTS.md](AGENTS.md).

## Base técnica preliminar

El MVP valida enrolamiento, identidad, seguimiento y distancia sobre superficies lisas, con procesamiento local. El transporte de cargas significativas y los terrenos irregulares quedan para futuras iteraciones.
