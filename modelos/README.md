# Modelos y artefactos de IA

No hay modelo seleccionado ni pesos versionados. Ver [evaluación de IA](../docs/evaluacion-ia.md).

Registrar para cada candidato: detector o identificador, origen, licencia, versión/hash, preprocesamiento, resolución, dimensiones de representación, umbral, datos de calibración y procedimiento reproducible. Diferenciar PCA ajustado, covarianza, galería del enrolado, encoder y detector.

Los pesos grandes, imágenes, secuencias y embeddings personales se mantienen fuera de Git. Versionar recetas y resultados agregados, no el entorno .venv ni artefactos personales. Elegir rutas y retención local antes de generar datos; no hay descarga automática configurada.
